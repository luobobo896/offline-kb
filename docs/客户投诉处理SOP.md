# 客户投诉处理 SOP

## 处理时效

- 首次响应：2 小时内。
- 给出方案：24 小时内。
- 闭环回访：处理完成后 3 天内。

## 分级

一般投诉：由一线客服处理，补偿权限 200 元以内。
升级投诉：主管介入，补偿权限 2000 元以内。
重大投诉：涉及媒体、监管、人身安全的，30 分钟内上报负责人。

## 处理原则

1. 先安抚情绪，再讨论方案。
2. 不承诺没有权限的事。
3. 每一条投诉必须留下文字记录与处理结果。
4. 涉及退款的，按资金审批流程执行，不得私下处理。

## 常见补偿口径

服务延迟：按订单金额 10% 补偿，上限 100 元。
设备故障：免费维修或更换，必要时全额退款。
态度问题：核实后以道歉 + 优惠券为主，不做现金补偿。
