# 数据安全与保密规范

## 数据分级

公开级：可对外宣传的资料。
内部级：仅限公司员工访问，如制度、流程、内部通讯录。
机密级：客户数据、财务数据、合同、源代码。
绝密级：密钥、支付凭证、身份证信息。

## 访问原则

最小权限原则：只授予完成工作所必需的权限。
机密级数据访问需部门负责人审批，并保留审计日志。
绝密级数据不得落本地磁盘，必须存放于加密存储。

## 禁止行为

- 禁止将客户数据发送到个人邮箱、网盘、聊天工具。
- 禁止使用未经审批的第三方 AI 工具处理机密数据。
- 禁止在公开仓库提交密钥、配置、数据库备份。
- 禁止私自复制、导出、带走公司数据。

## 离职处理

离职当天收回所有账号权限，交接文档由主管确认，个人设备上的公司数据必须删除并书面确认。
