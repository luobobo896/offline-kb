# 企业知识库 Demo（离线版）

给中小企业做的内部文档问答原型：把散落的制度、流程、手册变成一个能提问的知识库。
**完全离线运行，零第三方依赖，数据不出内网**——这是它对企业客户最有价值的一点。

## 快速开始

```bash
cd kb-demo
python3 kb.py ingest      # 建立索引（读 docs/ 下的 md）
python3 kb.py serve       # 启动，打开 http://127.0.0.1:8787
```

只需要 Python 3，不需要 pip install 任何东西。

## 它现在能做什么

| 能力 | 实现方式 |
|---|---|
| 文档导入 | 支持 Markdown / 纯文本，自动按标题与段落分块 |
| 中文检索 | 中文二元组分词 + 英文词切分，无需分词词典 |
| 双路召回 | BM25 关键词 + TF-IDF 余弦，按覆盖率加权融合 |
| 带引用回答 | 每条回答标注《文档》/章节，出处可点开看原文全文（`/doc?name=…`），可核对 |
| 相关性下限 | 关键词碰巧重合的无关片段不返回；命中不足时明确说「没有找到相关制度」并提示可能是权限原因 |
| 文档级权限 | 文档 frontmatter 标 `audience`，按角色过滤（已验证：普通员工查不到财务制度，点原文链接同样 403） |
| 演示模式 | URL 带 `?q=…&role=…&typing=1` 时，页面会逐字打出问题再检索，方便录屏/演示 |
| 接大模型（可选） | 配 `KB_LLM_URL/KEY/MODEL` 环境变量后自动切换为生成式回答 |

## 目录结构

```
kb-demo/
├── kb.py            # 全部逻辑：分块、索引、检索、Web 服务（约 420 行）
├── docs/            # 示例文档（7 份脱敏企业制度）
├── index.sqlite3    # 索引文件
└── README.md
```

## 3 分钟演示脚本

1. **普通员工查报销**：问「出差住宿报销上限是多少」→ 秒回，带《员工报销制度》出处。
2. **权限演示**：角色切到「普通员工」问「月度结账几号前完成」→ 查不到；
   切成「财务」再问 → 命中《财务内部核算指引（仅财务部可见）》。
3. **讲部署**：拿走 `kb-demo/` 整个目录，放到客户内网任意一台机器（甚至一台 NAS），
   把客户的文档丢进 `docs/`，跑两行命令就完成交付。全过程不联网。

## 能力边界（对客户也要讲清楚）

- 当前默认是**抽取式回答**（返回原文片段 + 出处），不是生成式。好处是不会编造，坏处是不够像人话。
- 接上大模型后是生成式，但需要客户提供模型 API 或本地 GPU。
- 检索目前是词法 + TF-IDF 向量；换成语义向量（bge + pgvector）是升级项，不是默认版。

## 常见客户问题

**数据会不会传出去？**
不会。默认版全程在本机/内网运行，代码里没有对外的网络请求。接入大模型是可选升级，客户可以选择本地模型。

**要不要买 GPU？**
基础版不需要。要接大模型时，用 API 或一台带 GPU 的机器都行，按客户安全要求选。

**维护成本多少？**
文档更新后重跑一次 `ingest` 即可，几秒钟。也可以做成定时任务。

**和市面上的产品比呢？**
SaaS 版功能多但要按人头付费、数据出内网；我们做的是私有化 + 按需定制，适合 10–200 人、文档敏感的公司。
